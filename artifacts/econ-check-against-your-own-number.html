A transferable teaching pattern · ECON 3916 / 5200 example

Check the AI Against Your Own Number

Students do a step by hand first. Then the AI does the same step, and the student checks it against the number they already have. The grade is for the checking, not for the AI's code.
The pattern (any discipline): the student produces a result themselves → the AI produces the same result → the student compares the two against a value they trust, fixes their prompt once, and explains the key step in their own words. You can't check what you couldn't have done yourself, so the AI only gets tasks the student could do.

Before

Each lab ended with a ready-made prompt. Students pasted it and got back a whole dashboard they could not have written, so they had no way to tell whether it was right. The lab taught pasting.

After

Students write a short function by hand, then ask the AI to write the same one. They run both, compare the results against the number the lab already computed, revise their prompt once to fix a flaw they found, and explain two lines of the code in their own words.

Student prompt
I computed a bootstrap standard error for the mean by hand in Step 4 of this lab: 0.41. Write a Python function boot_se(x, reps=1000) that does the same. Comment each line.
AI
Here is the function: 
def boot_se(x, reps=1000):
    means = [np.mean(np.random.choice(x, len(x), replace=False))
             for _ in range(reps)]
    return np.std(means)
Student check
Your function returns 0.00, not 0.41. You sample without replacement, so every "resample" is the same data in a different order and every mean is identical. A bootstrap has to sample with replacement. My revised prompt now says so explicitly.
AI
You're right. With replace=True the function returns 0.41, matching your Step 4 value.

Illustrative numbers. The real labs name the exact value to match, for example "your table must reproduce the 0.532 from Step 12."

AI-THINK

Verification against an independent value the student trusts, not "it ran, so it's right."

AI-DATA

Sees how code can run cleanly and still be wrong in a way only a check reveals.

AI-ETHICS

Ownership: students submit the full chat and explain the lines they hand in.

AI-CREATE

Judgment about when to stop, and when to do a step without AI.

Adapt it: Writing: the student outlines the argument first, the AI drafts, and the student checks every claim against their outline and sources. History: the student dates and places a document, then checks the AI's reading of it. Policy: the student computes the cost per person served by hand, then checks that the AI's table reproduces it. Do it yourself once, then check the AI against it.
